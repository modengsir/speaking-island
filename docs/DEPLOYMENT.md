# 独立部署

## 环境变量

| 变量 | 用途 | 默认行为 |
| --- | --- | --- |
| `MING_API_KEY` | 百灵服务端 API 密钥 | 空时只体验缓存配音与图卡 |
| `APP_ORIGIN` | 反向代理外部页面源，例如 `https://your-domain.example` | 空时按服务端收到的请求 URL 校验同源 |
| `APP_PASSWORD` | 家长访问口令，Basic 用户名为 `parent` | 开发仅本机可调用；生产语音关闭 |

本地将 `.env.example` 复制为 `.env.local` 后填写。正式环境使用托管平台的服务端 Secret 配置，或服务器本地、不会进入 Git 的环境文件。所有变量都不使用 `NEXT_PUBLIC_` 前缀。

## Node.js 服务器

```bash
npm ci
npm test
npm run typecheck
npm run build
npm start
```

`npm start` 监听 `127.0.0.1:3000`。在同一服务器用 HTTPS 反向代理转发到该地址，保留请求的 Host、Origin 和 Authorization 头，并将 `APP_ORIGIN` 配置成用户访问的外部源（协议加域名，如 `https://your-domain.example`）。这可避免代理后的内部 HTTP 地址与浏览器 HTTPS 源不一致。需要为顺序模型调用留足请求超时，例如 100 秒。

容器或平台需要对外监听时，启动命令为 `npx next start --hostname 0.0.0.0 --port 3000`，或将端口改成平台分配值。在实际提供服务的运行环境中设置两个变量；只有构建时设置密钥不等于运行时已配置。

## 访问和成本

配置 `APP_PASSWORD` 后，首次访问页面会出现浏览器登录框，用户名为 `parent`，密码为你设置的值。API 由浏览器携带同源的 Basic 授权。部署到公网需使用 HTTPS。插画和固定示范素材是公开资源，不包含用户录音。

不要把 HTTP Basic 共享口令当作孩子账号系统。应用当前没有注册、邮箱、密码找回、会话数据库或个人云端学习档案。登录缓存由浏览器管理，关掉标签页不一定清除；共用设备体验完毕后应按浏览器方式清除登录状态。

每个 Node 进程共享每分钟 20 次语音请求的内存限流，服务重启后清空，多实例之间不共享。提供方仍可能单独限流。面向多人正式开放前，需要替换为独立用户授权和共享配额，并在提供方账户设置预算。现有 GitHub Actions 不包含任何发布步骤。

## 上线前手动验证

1. 未登录访问主页应出现家长口令提示；错误口令不能请求在线语音。
2. 用正确口令登录，在家长空间用固定合成样例验证转写和理解状态。
3. 自行确认 HTTPS、浏览器麦克风权限、录音停止与错误提示。
4. 确认服务器、反向代理与监控没有记录请求正文或 Authorization。

## 常见情况

- **只听得到示范，录音按钮打开家长空间**：检查运行时密钥与访问口令；生产环境不会无口令开放语音。
- **已配置但请求失败**：配置状态只检查密钥是否存在。连接检测才实际调用；检查账号权限、网络、额度或提供方限流。
- **429**：可能是应用每分钟请求上限，也可能是百灵的限流；界面会区分提示。
- **无麦克风**：页面需 HTTPS 或 localhost，且浏览器和系统均允许麦克风。
- **中文不出声**：系统未安装中文音色时只显示文字，英文缓存仍可播放。
- **audio-flash 暂未返回**：结果会明确显示使用转写规则，不能将该次记为理解模型成功。
