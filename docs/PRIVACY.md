# 隐私与数据流

## 收集与传输

孩子由家长陪同练习。应用先展示录音说明，经监护人确认后才申请麦克风。录音最长 8 秒，由浏览器通过同源接口发送给应用服务端，再发送给百灵 ASR 和音频理解接口。固定 TTS 请求只包含白名单引导文本，不包含孩子录音。

应用不需要姓名、生日、学校、邮箱或定位，也不尝试通过声音判断身份、年龄、情绪、健康或口音等级。声音只用于转写和当前任务内容匹配。

## 留存位置

| 数据 | 应用内保存位置 | 清除方式 |
| --- | --- | --- |
| 水果、颜色、任务完成方式与时间 | 当前浏览器 localStorage | 家长空间「清除」或浏览器清理站点数据 |
| 最近一段录音 | 当前页面 Blob URL / 内存 | 新录音覆盖、刷新、关闭页面或家长清除 |
| 最近 30 条真实识别结果 | 当前页面内存 | 刷新、关闭页面或家长清除 |
| 主动导出的 JSON | 用户选择的下载目录 | 由用户删除下载文件 |
| 服务端请求音频 | 请求处理内存 | 请求结束后不由应用写入持久存储 |

应用代码不记录录音、转写、API 密钥或 Authorization 请求头；提供方异常日志只含固定路径和状态码。服务器、托管平台、反向代理可能另有访问日志配置，部署者需检查自己的设置。百灵处理与保留规则由其服务政策决定，本仓库不能替提供方承诺不留存。

## 仓库素材

仓库中的英文配音和连接检测音频均为合成样例，不包含真实儿童录音。Issue、PR 和自动化测试请使用合成或获得授权的成人样例，不上传孩子录音、识别原文或账号密钥。

## 内容反馈

反馈只代表录音内容是否完成某项固定任务，不用于发音诊断或儿童能力评估。没有真实儿童研究数据或学习效果保证。
